| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-9-06 | Elevation | client Save-disable / serviceability gate | accept | The origin gate + Save-disable are UX conveniences; the enforced boundary is `site_content_admin_write` RLS + the server-side admin check in the edge function. A non-admin cannot upsert site_content regardless of the UI. |
| T-9-07 | Tampering | 000000 persisted as real origin | mitigate | deliverySchema rejects 000000 (09-01) AND Save is disabled until checkServiceable returns ✓ (D-10) |
| T-9-08 | Info disclosure | purge/preview errors surfaced to admin | mitigate | Purge failure is logged + tolerated (no cache internals leaked); preview reuses the generic EstimateError mapping |
| T-9-SC | Tampering | npm/pip/cargo installs | accept | No package installs in this phase (RESEARCH § Package Legitimacy Audit — not applicable; all libs already in package.json) |
