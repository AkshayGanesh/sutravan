## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser/any client → delivery-estimate Edge Function | Untrusted, anonymous input crosses here (verify_jwt=false); the only server seam a static SPA can hold a secret behind |
| Edge Function (service role) → Postgres | Elevated access; the function is the sole writer of the deny-direct cache |
| Edge Function → Cloudflare Turnstile siteverify | Secret custody boundary for TURNSTILE_SECRET_KEY |

| T-6-07 | Denial of Service | anon endpoint scraping / price oracle | mitigate | Turnstile siteverify gates compute + 24h `delivery_estimate_cache` + server-side `/^\d{6}$/` validation BEFORE compute + upstream `AbortController` timeout (Pitfall 4/7). |
| T-6-08 | Information Disclosure | raw Postgres/PostgREST errors | mitigate | Generic `{ error: 'bad_request' }` responses; `console.error` server-side only; never reflect column/constraint text (CR-01 / D-21). |
