## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → `delivery-estimate` Edge Function | Untrusted pincode + single-use Turnstile token; error codes returned to the client |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-05 | Information disclosure | error rendering | mitigate | The block renders only the mapped generic copy ("Couldn't get an estimate…"), never the raw function/Postgres error; the function already returns generic codes (`bad_request`/`captcha_failed`) and strips the internal `zone` field |
| T-07-06 | Spoofing/DoS | Try-again retry loop | mitigate | Each retry resets Turnstile so a fresh single-use token is required per attempt — no token replay, no unbounded no-captcha retries |
| T-07-07 | Tampering | free-ship threshold render | accept | `delivery_free_ship_threshold` is public site_content read via the existing `['siteContent']` path; rendered as a numeric-formatted string only (no injection surface) |
| T-07-SC | Tampering | client dependencies | mitigate | No npm installs — Skeleton/Input/Button/Badge are existing shadcn components; Turnstile stays on the hosted-CDN loader; `@marsidev/react-turnstile` forbidden |
</threat_model>
