<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| admin browser → delivery_rate_slabs (PostgREST upsert) | Untrusted client attempts a write; authorization MUST be enforced server-side by RLS, never by UI hiding |
| admin browser → delivery-estimate edge function ({purge:true}) | Untrusted invoke of the cache-purge branch; admin-gating enforced inside the function |
| delivery_rate_slabs → customer estimate | The slab table is the sole rate source behind the normalized contract; changes must not alter the contract shape |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-02 | Elevation of Privilege | delivery_rate_slabs upsert | mitigate | Authenticated non-admin upsert is rejected by the PRE-EXISTING `delivery_rate_slabs_admin_write` RLS policy (`using/with check (private.is_admin())`, migration 0016 lines 43-47). Same pattern already proven for site_content in Phase 9. No new policy; the UI hiding the nav item is defense-in-depth, NOT the boundary. Verify (10-03) that a non-admin write fails. |
| T-10-03 | Tampering | invalid/negative/₹0 cost bypassing client zod | accept | The write is admin-only (T-10-02 gate); an admin who bypasses client validation could POST cost=0/negative because table `cost` has NO DB CHECK for positivity (0016 line 24). Accepted: writers are trusted admins; `rateSlabsSchema` (cost ≥ ₹1, D-08) is the practical guard and SC3's "no silent ₹0" holds for the normal UI path. Optional future hardening: add a `check (cost >= 1)` DB constraint (NOT done this phase — no schema change per phase scope). |
| T-10-04 | Elevation of Privilege | delivery-estimate {purge:true} | mitigate | The purge branch already returns 403 for a non-admin caller and deletes cache only via the service role (index.ts lines 395-411); reused verbatim, no change. A non-admin purge call is rejected server-side. |
| T-10-05 | Information Disclosure | delivery_rate_slabs public read | accept | Slab rates are non-sensitive placeholder tariff numbers the estimator needs; public-read RLS (0016 lines 38-41) is intentional and unchanged. |
| T-10-SC | Tampering | npm installs | accept | No new dependencies this phase — RHF, zod, @tanstack/react-query, sonner, shadcn primitives, supabase-js all already installed. No package-legitimacy gate required. |
</threat_model>
