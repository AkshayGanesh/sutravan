<objective>
Deliver the admin-protection slice: an `AdminGuard` route guard with a loading gate (D-12) and the exact D-11 redirect policy, an empty protected `/admin` shell (portal content is Phase 4), and the post-login return-to-destination handoff (D-10). This guard is the UX layer backing the real RLS enforcement (AUTH-05). This plan owns the `App.tsx` `/admin/*` route addition.

Purpose: Gate the admin portal's UI namespace and prove the guard with an empty shell, without leaking the admin area's existence and without flashing/bouncing on refresh.

</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client route guard -> protected /admin UI | UX-only boundary; the guard hides UI but the REAL enforcement is RLS server-side. |
| remembered return-to destination -> post-login navigation | Untrusted-looking value that must not enable open redirect. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-3-12 | Information Disclosure | a 403/"access denied" page advertises the admin area exists | mitigate | No 403 page; non-admins are redirected to `/` (D-11). |
| T-3-08 | Spoofing | guard decides before session/role resolves -> flashes admin UI or bounces a refreshing admin | mitigate | Loading gate renders a Spinner and defers all decisions until `loading` is false (D-12, Pitfall 2). |
| T-3-10 | Spoofing | open redirect via the remembered `/admin` return-to value | mitigate | Destination restricted to internal leading-slash paths; reject `://`/`//` (Pitfall 6, D-10). |
| T-3-13 | Elevation of Privilege | a customer bypasses the UI guard via raw PostgREST | accept (by design) | The guard is UX-only; RLS `private.is_admin()` (0002) is the real boundary and is unaffected by client routing — a guard bypass grants no DB access (AUTH-04). Documented design note. |
| T-3-SC | Tampering | npm installs | accept | No new package installs — all deps pre-existing (RESEARCH Package Legitimacy Audit: N/A). |
</threat_model>
