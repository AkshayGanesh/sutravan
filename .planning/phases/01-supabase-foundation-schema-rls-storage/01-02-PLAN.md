<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| anon / customer (anon key) → Postgres via PostgREST | Untrusted client crosses into the DB; RLS is the only real authz |
| customer (authenticated) → other users' rows | A logged-in user must never read/write another user's profile/wishlist/submission |
| customer (authenticated) → catalog/content/storage writes | Only admins may write catalog tables and Storage objects |
| profiles RLS policy → profiles table | Self-referential read risks infinite-recursion if it queries profiles |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-RLSOFF | Elevation of Privilege | Any of the six tables shipped without RLS | mitigate | `enable row level security` emitted for ALL six tables (Task 2); rls_assertions.sql asserts `relrowsecurity = true` for each (Task 3) — caught before phase gate |
| T-02-ANONWRITE | Tampering / Elevation | anon/customer INSERT/UPDATE on catalog tables | mitigate | Default-deny + admin-write policies gated on `private.is_admin()`; no anon write policy exists; assertion confirms no public insert policy on profiles (Task 2/3) |
| T-02-ROLEESC | Elevation of Privilege | Privilege escalation via user-editable role | mitigate | `role` lives in `public.profiles` with `check (role in ('admin','customer'))`, never in auth metadata (D-10); profiles write is owner-self (cannot set own role to admin via the catalog path — admin-only update covers role changes); is_admin() reads profiles server-side (Task 1/2) |
| T-02-RECURSION | Denial of Service / broken authz | profiles self-read policy querying profiles | mitigate | is_admin() is SECURITY DEFINER (bypasses RLS, breaks the cycle); profiles self-read uses `(select auth.uid()) = id` and never calls is_admin() (Task 1/2) [VERIFIED: discussions #1138/#32579] |
| T-02-SEARCHPATH | Elevation of Privilege | search_path hijack on the DEFINER function | mitigate | `set search_path = ''` on is_admin() and every object fully-qualified (`public.profiles`, `auth.uid()`); assertion checks proconfig has search_path (Task 1/3) |
| T-02-XUSER | Information Disclosure | One customer reads another's wishlist/submission | mitigate | Owner-scoped `(select auth.uid()) = user_id` USING + WITH CHECK on wishlists; submissions read scoped to admin-or-owner (Task 2) |
| T-02-STORWRITE | Tampering | Non-admin writes/overwrites catalog images in Storage | mitigate | storage.objects insert/update/delete policies require `bucket_id = '<bucket>' and private.is_admin()`; public read only (Task 3) |
</threat_model>
