<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| admin form → products table | Writes ride the admin JWT; RLS is_admin() gates them |
| draft product → public Shop | Draft rows must never reach anon (CR-01 + draft default) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-13 | Information Disclosure | new product visibility | mitigate | New products default is_active=false (D-08) AND CR-01 (0005) makes drafts unreachable via raw PostgREST — verified in Task 3 step 4 |
| T-04-14 | Tampering / Input Validation | product form fields | mitigate | Zod schema validates name/category required, price coerced to non-negative integer or null; RLS rejects writes from non-admins regardless of client validation |
| T-04-15 | Tampering | orphaned images on delete | mitigate | useDeleteProduct (Plan 03) calls removeProductImages with the row's storage paths |
| T-04-SC | Tampering | npm installs | n/a | No installs in this plan |
</threat_model>
