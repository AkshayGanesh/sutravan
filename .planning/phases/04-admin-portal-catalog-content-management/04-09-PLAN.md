<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| uploaded file bytes → image pipeline → Storage | Untrusted device file; must be validated, re-encoded, and size-bounded before it reaches the public bucket |
| admin upload/remove → storage.objects | Writes ride the admin JWT; storage.objects admin policies (0003) gate them |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-24 | Tampering | malicious file upload (script/SVG masquerading as image) | mitigate | assertImageAllowed MIME+extension allow-list (JPEG/PNG/WebP/HEIC) + 10MB cap; processImage re-encodes through browser-image-compression to JPEG, stripping active content; bucket is public-read images only |
| T-04-25 | Denial of Service | oversized phone photo | mitigate | reject >10MB BEFORE any conversion CPU (Pitfall 3); compress to ~1MB/1600px target |
| T-04-26 | Tampering | orphaned Storage objects on replace/remove/delete | mitigate | removeProductImages deletes objects on saved-image remove and on product delete (Pitfall 2) — verified Task 2 step 6 |
| T-04-27 | Elevation of Privilege | non-admin Storage write | mitigate | storage.objects product_images_admin_insert/update/delete (0003) reject non-admin writes server-side |
| T-04-SC | Tampering | npm installs (heic2any, browser-image-compression) | mitigate | Verified in Plan 02 Task 1 (slopcheck [OK], [ASSUMED] gated); no new installs here |
