# Quick Task 260602-t02: Per-product admin toggle to show "Always patch test first." Summary

Added a per-product `show_patch_test_note` display flag (default false, opt-in) wired end-to-end: a visible "Show patch-test note" Switch on the admin ProductForm controls whether the fixed safety line "Always patch test first." renders on the public product detail — previously it was shown unconditionally for every product.

## What was built

- **Migration 0010** — `alter table public.products add column if not exists show_patch_test_note boolean not null default false;`. Default FALSE (opposite of 0008's in_stock), so all existing rows start with the note OFF and no backfill. Header documents the load-bearing invariant: this is a DISPLAY flag, not a visibility flag — zero RLS policy statements, write rides the existing `products_admin_write` (private.is_admin()) from 0002.
- **Data layer** — `Product.showPatchTestNote` added; `catalog.ts` `toProduct` maps `row.show_patch_test_note ?? false` and the `fetchProducts` select string now includes `show_patch_test_note` with NO `.eq()` filter (existing `.eq('is_active', true)` untouched). `admin.ts` carries the field in `ProductFormValues`, `ProductRow`, `fromProductForm` (`show_patch_test_note: v.showPatchTestNote`), and `ADMIN_PRODUCT_COLUMNS`. No new mutation hook — saved by the existing `useUpsertProduct` (which invalidates `['catalog']`).
- **Admin form** — visible "Show patch-test note" Switch on ProductForm (after the Published block), mirroring the Published Switch exactly: in the zod schema, both defaultValues branches (edit → `existing.show_patch_test_note ?? false`, new → `false`), and the onSubmit payload. FormDescription switches on `field.value`.
- **Public render** — the `<p>Always patch test first.</p>` paragraph in ProductDetail is now wrapped in `{product.showPatchTestNote && (...)}`; same text, styling, and placement. The batch-note / shelf-life line is untouched.
- **Tests** — `baseForm` default set to `showPatchTestNote: false`; new `fromProductForm show_patch_test_note mapping` describe block asserts true→true and false→false (TDD: committed failing first, then implemented).
