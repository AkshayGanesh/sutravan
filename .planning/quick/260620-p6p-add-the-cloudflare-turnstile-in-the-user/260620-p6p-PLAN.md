<objective>
Add Cloudflare Turnstile bot-protection to the three unauthenticated auth surfaces (Login, Register, Reset-password REQUEST) using Supabase's NATIVE CAPTCHA path: the client renders the Turnstile widget, obtains a token, and passes it as `options: { captchaToken }` to the relevant `supabase.auth.*` call. Output: One reusable `TurnstileWidget` component plus token wiring in the three pages; the RECOVERY set-new-password sub-form is intentionally left untouched.
